02 / Quick start

Reproduce two headline result figures

The repository documents a lightweight workflow that uses its compact result tables. It does not need the full posterior samples or another Bayesian sampling run.

01Get the repository

Clone the source code, documentation and available derived outputs.

02Build the environment

Use the provided Conda specification (Python 3.12, PyMC 6, scientific Python).

03Run figure script

Read the included global, block and spatial-location tables; create the two output PNGs.

Terminal commands
git clone https://github.com/afififtikharkues19-RGB/Rupsha-Pasur-Morphodynamics.git
cd Rupsha-Pasur-Morphodynamics
conda env create -f environment.yml
conda activate rupsha-pasur-morphodynamics
python src/results_figures.py

Large and sensitive materials

The research repository excludes raw Landsat scenes, annual raster water masks, topology-support rasters, large intermediate GeoPackages, full posterior NetCDF files, Monte Carlo realizations and temporary QC products.

Source imagery remains with the original provider. No household-level records, interview transcripts or identifying participant information have been added to this hub. Only already-public summaries and links are included.

Read the data-availability statement ↗

Scientific and computational limits

The primary posterior uses nominal geometry; the 2,000-realization geometry ensemble was separate. The final model retains two divergences and cannot reproduce the large concentration of exact-zero mapped displacements. Residual spatial dependence is documented.

These issues are not erased by the availability of code. The manuscript remains in final preparation; conditional associations are not established causal mechanisms.
